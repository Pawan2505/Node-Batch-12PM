# Node.js Batch (12 PM)

This repository contains all **lecture codes, practical examples, and projects** from the **Node.js Batch (12 PM)** training program.  
It covers **Node.js fundamentals, Express.js, EJS templating, middleware, routing, MongoDB, CRUD operations, admin panel development, Passport.js authentication, and more**.

---

## 📚 Topics & Folders Covered

### 🔹 Introduction & Setup
- `01_Introduction` → Introduction to Node.js  
- `02_Install Node` → Node.js installation  
- `03_REPL Global Object` → REPL & global objects  
- `04_Module` → Node.js modules  

### 🔹 HTTP & Express
- `05_http server` → Creating HTTP server  
- `06_express server` → Express.js setup  
- `07_express_ejs` → Express with EJS templating  
- `08_ejs_crud` → CRUD using EJS  

### 🔹 Middleware & Routing
- `09_middleware` → Middleware functions  
- `10_mongodb` → MongoDB setup & connection  
- `11_routing` → Routing in Express  
- `12_mvc_crud` → MVC CRUD operations  
- `13_mvc_crud -sync-await-try-catch` → CRUD with async/await & error handling  
- `14_mvc_crud -sync-await-try-catch` → Continuation  

### 🔹 Admin Panel & Authentication
- `15_admin_panel` → Admin panel CRUD  
- `16_admin_panel` → Forget password feature  
- `17_mern_project` → Frontend & backend connection  
- `18_admin_panel_forget_Password` → Forget password with Nodemailer  
- `19_admin_panel_passportjs` → Passport.js authentication  
- `20_admin_passport_js` → Passport.js configuration  
- `21_admin_panel_passportjs_session_completed` → Passport.js session handling  
- `22_crud-passportjs_complete` → Complete CRUD with Passport.js  

### 🔹 Enhancements & Utilities
- `23_admin_panel_flash` → Flash messages & SweetAlert2  
- `24_admin_panel_sweetalert2` → Flash & SweetAlert2 integration  
- `25_crud-passportjs` → Categories, subcategories, extra categories  
- `26_crud-passportjs_complete` → Completed CRUD with categories  
- `27_admin_panel_add_Category` → Add category functionality  
- `28_admin_panel_SubCategory_Complete` → Subcategory management  
- `29_admin_panel_Extracategory` → Extra category management  
- `Cookie and Sessions` → Handling cookies & sessions
